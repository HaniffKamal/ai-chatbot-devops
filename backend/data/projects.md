# Highlight Projects & Architecture

## AI Chatbot & MLOps Infrastructure Platform (`ai-chatbot-devops`)
- **Repository:** `github.com/HaniffKamal/ai-chatbot-devops`
- **Architecture Overview:** An independent, on-demand AI microservice designed to power an interactive chat assistant embedded on Haniff's master portfolio website (`haniffkamal.my`).
- **Decoupled System Boundary:**
  - The master portfolio frontend is statically hosted 24/7 on Cloudflare Pages for maximum uptime and zero hosting costs.
  - This microservice is hosted on an on-demand AWS EC2 instance (`m7i-flex.large`) and runs a local inference and RAG pipeline.
- **Key Architectural Components:**
  1. **Nginx Reverse Proxy:** Serves the frontend chat widget and proxies `/api/` traffic to the backend with hardened security headers and CORS controls.
  2. **FastAPI Async Backend:** High-performance REST service utilizing connection pooling (`httpx.AsyncClient`) and strict Pydantic input validation.
  3. **Embedded ChromaDB RAG Pipeline:** In-process vector database indexing markdown knowledge chunks to eliminate hallucination without dedicated database server overhead.
  4. **Dual-Engine Inference:** Prioritizes local Ollama inference (`llama3.2:1b`) with automated fallback to Groq Cloud API if local capacity is unavailable.
  5. **Automated Infrastructure:** Fully reproducible AWS environment provisioned via Terraform and configured via idempotent Ansible playbooks.
  6. **Observability:** Prometheus metrics scraping coupled with auto-provisioned Grafana telemetry dashboards.

## Audio Deepfake & Voice Spoofing Detection Engine
- **Focus:** Developing robust deep learning models capable of distinguishing human voice recordings from synthetic audio generated by modern vocoders (WaveGlow, HiFi-GAN, diffusion vocoders).
- **Core Technology:** Mel-spectrogram & LFCC acoustic feature extraction pipelines, PyTorch convolutional neural networks (ResNet), and data augmentation against environmental noise.
- **Outcome:** High-accuracy classification evaluated on ASVspoof benchmarks, designed for integration into secure biometric authentication workflows.
